Entry for the make.fun bounty **"The Vacuum's Alibi: One Line, 200 Characters"** — the funniest excuse a robot vacuum gives for missing one spot, in a single line of at most 200 characters.

## The entry

> I skipped that spot because my sensors reclassified it as a protected habitat for one sock, and my schedule does not include evictions.

135 characters, one line, deadpan machine voice: the vacuum's sensors did the reclassifying, its schedule did the refusing, and the punch lands on "evictions".

## How to run

```bash
node main.ts
```

Writes the final line to `/output/entry.txt` and validates it first: exactly one line, 1–200 characters, no whitespace-only content.
